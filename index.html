🐾 What is GitHub?

GitHub is a platform where programmers store, share, and collaborate on code. It also lets you host websites for free using GitHub Pages.

🐾 Steps to Create Your Website

  1. Create a GitHub account.
  2. Click Repositories.
  3. Create a new repository called yourusername.github.io.
  4. Add a README file.
  5. Upload your website files.
  6. Make sure the homepage is named index.html.
  7. Commit your changes.
  8. Visit yourusername.github.io.
